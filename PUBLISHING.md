# Maven Central Publishing Guide

The SDK is automatically published to [Maven Central](https://central.sonatype.com/artifact/io.github.oguzhaneksi/media3watch-sdk) via GitHub Actions when a release is created.

---

## Prerequisites

Before the first publish, you need:

1. A **[Sonatype Central Portal](https://central.sonatype.com/)** account (sign up with your GitHub account for automatic `io.github.<username>` namespace verification)
2. A **GPG signing key** (generated below)
3. **5 GitHub Secrets** configured (listed below)

---

## Step 1 — Generate a GPG Signing Key

Run the helper script from the project root:

```bash
chmod +x generate_safe_key.sh
./generate_safe_key.sh
```

The script generates a BouncyCastle-compatible key (AES256 + SHA512, no AEAD), optionally uploads the public key to a keyserver, exports the secret key as Base64 to your clipboard, and prints the values you need for GitHub Secrets.

> **Why a custom script?**  
> GnuPG 2.3+ on macOS encrypts keys with an AEAD/OCB algorithm that Gradle's BouncyCastle library cannot read, causing `Could not read PGP secret key` errors. The script forces the older, compatible format.

---

## Step 2 — Configure GitHub Secrets

Go to your repository → **Settings → Secrets and variables → Actions** and add these 5 secrets:

| Secret | Where to get it |
|--------|----------------|
| `SONATYPE_USERNAME_TOKEN` | [central.sonatype.com](https://central.sonatype.com/) → Profile → Generate User Token → **Username** |
| `SONATYPE_PASSWORD_TOKEN` | Same token generation → **Password** |
| `OSSRH_GPG_SECRET_KEY` | Script output — paste from clipboard |
| `OSSRH_GPG_SECRET_KEY_ID` | Script output — printed as "Key ID (short)" |
| `OSSRH_GPG_SECRET_KEY_PASSWORD` | The passphrase you entered in the script |

---

## Step 3 — Release

1. Bump `VERSION_NAME` in `android/gradle.properties` (e.g. `1.0.0-alpha01` → `1.0.0-alpha02`)
2. Commit and push to `main`
3. On GitHub → **Releases** → **Draft a new release**
4. Create a tag matching `VERSION_NAME` (e.g. `v1.0.0-alpha02`)
5. Click **Publish release**

The `Publish SDK to Maven Central` workflow starts automatically:
- **validate** job: runs `publishToMavenLocal` to verify POM, GPG signing, and artifact structure
- **publish** job: uploads and releases to Maven Central (only if validate passes)

New versions appear on Maven Central search within ~15–30 minutes.

---

## Troubleshooting

| Error | Cause | Fix |
|-------|-------|-----|
| `Could not read PGP secret key` | Key was generated by GPG 2.3+ with AEAD | Re-generate with `generate_safe_key.sh` |
| `401 Unauthorized` | Invalid Sonatype token | Regenerate token at central.sonatype.com |
| `Namespace not verified` | `io.github.oguzhaneksi` not registered | Sign in to central.sonatype.com with GitHub to auto-verify |
| `Missing required POM fields` | POM metadata incomplete | Check `mavenPublishing { pom { } }` block in `sdk/build.gradle.kts` |
| Publish job skipped | `validate` job failed | Check logs for the dry-run failure and fix before retry |
